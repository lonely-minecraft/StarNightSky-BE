StarNightSky BE 説明書
======================

マインクラフト統合版の夜空に、本物の星空を映すリソースパックです。
星座線や星座名の入った夜空が、時間とともにゆっくり回ります。

作者: damun-craft.com
      https://damun-craft.com/
バージョン: 1.0.1

これはマインクラフトの公式の製品ではありません。Mojang や Microsoft が認めたものでも、関わっているものでもありません。


■ 動作を確認した環境
------------------------------
・Windows 版 v26.52 で動作を確認しました。
・ほかの機種(スマホ、Switch、ゲーム機など)やバージョンでは確認していません。
・マルチプレイでの動作は確認していません。


■ 入れ方(Windows)
------------------------------
1. マインクラフトを終了します。
   (マインクラフトを開いたままだと、取り込まれないことがあります。)
2. StarNightSky_BE.mcpack をダブルクリックします。
   マインクラフトが起動して、「インポート完了」と表示されます。
3. ワールドの設定を開き、「リソースパック」で StarNightSky BE を有効にします。
4. ワールドに入り、夜になるのを待ちます。
   F5 キーで三人称の視点にすると、星空が見えます。

ダブルクリックで取り込めないときは、手で入れることもできます。
1. StarNightSky_BE.mcpack の名前の最後を .zip に変えて、展開します。
2. 展開したフォルダ(中に manifest.json があるフォルダ)を、次の場所に入れます。
   Windows キー + R を押し、出てきた欄に次を貼り付けて Enter を押すと、その場所が開きます。
   %appdata%\Minecraft Bedrock\Users\Shared\games\com.mojang\resource_packs
3. マインクラフトを起動します。


■ パックの設定
------------------------------
ワールドの設定の「リソースパック」で、有効にした StarNightSky BE の歯車ボタンを押すと、設定画面が開きます。

・夜空の種類
    次の5種類から選べます。最初は「星＋星座線＋星座名」です。
    - 星だけ
    - 星＋星座線
    - 星＋星座線＋星座名
    - 星＋星座線＋星座名＋星座絵
    - 天の川の見える本物の星空(NASA)

・星座線の形
    「星＋星座線」と「星＋星座線＋星座名」の夜空で、星座線の形を選べます。最初は「標準」です。
    - 標準: 国際天文学連盟(IAU)のウェブサイトの星座図にもとづく線です。
      (IAU が正式に決めているのは星座の境界だけで、星座線に公式の決まりはありません。)
    - H.A.レイ方式: 絵本作家の H.A.レイが考えた、星座の名前どおりの姿に見えやすい線です。
      おおぐま座やペガスス座などは、標準と向きが違います。
    星座絵は、標準の線のときだけ表示されます(絵が標準と同じ昔ながらの向きで描かれているため)。
    「星＋星座線＋星座名＋星座絵」でH.A.レイ方式を選ぶと、星座絵のない「星＋星座線＋星座名」(H.A.レイ方式)になります。

・描画距離(チャンク)
    「設定」→「ビデオ」の「描画距離」と、同じ値にしてください。最初は 16 です。
    合っていないと、次のようになります。
    - 小さすぎると、遠くの山や森の手前に星が描かれます。
    - 大きすぎると、星空が消えたり、一部が欠けたりします。
    ビデオ設定の描画距離を変えたときは、こちらも変えてください。

・一人称の視点でも表示する(最初はオフ)
    一人称の視点では、星空が視点と一緒に動いてしまい、地面や建物の手前にも描かれます。
    そのため、最初は一人称のときに星空を隠しています。

・季節の移り変わり(最初はオン)
    星空が毎日少しずつずれ、8日で1年分の星空がめぐります。
    本物の空では、季節によって見える星座が変わります。それを縮めて再現しています。

・雨の日は星空を隠す(最初はオン)
    雨の夜は、星空を表示しません。屋根の下にいても隠れます。


■ 見え方について
------------------------------
・星空は、夕方(時刻 11500)から明け方(時刻 23500)までの夜の間だけ表示されます。
・星空は、太陽や月と同じ向きに、1日で1回転します。
・マインクラフトの太陽は真東から昇って真上を通るので、それに合わせて「赤道で見た星空」にしています。
  そのため、北極星は北の地平線すれすれにあります。日本で見る星空とは傾きが違います。
・太陽と月は、マインクラフトのものがそのまま見えます。本物の太陽や月のように、星座の間を動くことはありません。
・マインクラフトにもともとある星(架空の星)も、そのまま見えます。このパックでは消せません。


■ 困ったときは
------------------------------
・星空が見えない
    - 夜になっているか、三人称の視点になっているかを確かめてください。
    - 雨が降っていないかを確かめてください。
    - パックの設定の「描画距離」が、ビデオ設定と同じ値かを確かめてください。

・パックを外したのに、星空が残っている
    パックを外しても、マインクラフトを再起動するまで前の表示が残ることがあります。
    また、パックを外したあと、再起動する前にワールドに入ると、パックが有効に戻ることがあります。
    下の「外し方」の順番で、外し直してください。

・ほかのリソースパックと一緒に使うと、おかしくなる
    このパックは、プレイヤーの見た目の定義(player.entity.json)を書き換えています。
    同じ定義を書き換えるほかのパックと一緒に使うと、どちらかが効かなくなることがあります。

・マインクラフトの更新後に、プレイヤーの表示や動きがおかしくなった
    このパックは、動作を確認したバージョンのプレイヤーの定義をもとに作っています。
    マインクラフトが更新されてプレイヤーの定義が変わると、合わなくなることがあります。
    その場合は、下の「外し方」の順番で、このパックを外してください。


■ 外し方
------------------------------
1. ワールドの設定の「リソースパック」で、StarNightSky BE を外します。
2. ワールドには入らずに、マインクラフトを終了します。
3. マインクラフトを起動します。

外したあと、再起動する前にワールドに入ると、パックが有効に戻ることがあります。
(設定の画面からそのまま「遊ぶ」を押したときに、戻ることを確かめました。)
